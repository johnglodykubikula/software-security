# software-security
#Reflection

Artemis Financial is a financial services company that needed a more secure software application to protect sensitive customer information and financial data. The company wanted to address security weaknesses by improving secure communications and ensuring data integrity. During this project, I identified software vulnerabilities, analyzed dependency risks, and implemented security improvements such as HTTPS using TLS encryption and SHA-256 hashing. I believe I did well in recognizing potential security issues and applying secure coding practices to reduce risk. Secure coding is important because it helps prevent data breaches, protects customer information, maintains trust, and supports the overall stability and reputation of a business.

One of the most helpful parts of the vulnerability assessment was learning how to use security tools to identify weaknesses in software dependencies and determine appropriate mitigation strategies. To increase security, I added layers of protection through encryption, hashing, and dependency management. After refactoring the application, I tested the software to verify that it remained functional while also reviewing it for newly introduced vulnerabilities. Resources such as OWASP Dependency-Check, secure coding guidelines, Java security libraries, and vulnerability assessment techniques were valuable throughout the project and will be useful in future work. If I were demonstrating my skills to a future employer, I would showcase my vulnerability assessment, dependency analysis, security improvements, and secure code refactoring as evidence of my ability to identify risks and implement effective cybersecurity solutions.
